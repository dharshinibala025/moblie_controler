# assets

This folder is reserved for static assets belonging to the Admin Panel
module (e.g. custom images or logos).

All icons currently used in this module come from `react-native-vector-icons`
(`MaterialIcons` set), so no image files are required at this time. Drop any
future images here (e.g. `assets/images/`) and reference them with
`require('../assets/images/your-image.png')` from within `components/` or
`screens/`.
